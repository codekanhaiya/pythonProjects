## ⏰ MyClock.py

A minimal yet stylish **digital clock** application using Tkinter, which displays:

- Current system time (HH:MM:SS AM/PM)
- Day, date, and month
- Beautiful cyan-on-black theme
- Optional support for `ds-digital` font

### 🚀 How to Run

```bash
python MyClock.py
```

## 📝 MyTextEditor.py

An advanced GUI text editor like Notepad but with modern capabilities:

### 🔧 Features

- 🗂 File → Open, Save As

- ✂️ Edit → Undo, Redo, Cut, Copy, Paste, Select All

- 🌓 View → Toggle Dark/Light Mode

- 🧠 Status Bar with live character count

- 🛠 Built with Python tkinter, lightweight and cross-platform

### 🚀 How to Run
```bash
python MyTextEditor.py
```

### 🛠 Requirements

Python 3.6 or higher

No additional libraries required (tkinter is built-in with Python)
